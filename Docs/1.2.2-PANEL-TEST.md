# PanaLux 1.2.2 panel test

Quit your current PanaLux before opening the staged PanaLux.app. Keep Resolve closed so the panel is available. Use a disposable Lightroom photo. The test build preserves existing maps and trails; map edits can be undone with Command-Z.

1. Turn each of the twelve knobs, then press it. Confirm only its assigned Lightroom slider returns to Lightroom’s default. Include Pivot and Lum Mix. In Program Buttons, each press should identify the correct knob; report a mismatch rather than recalibrating around it.
2. Repeat a press with a different mode active and a selected mask. Confirm it resets the active parameter. A knob assigned to a navigation command should explain that there is no reset.
3. Set distinct color and luminance values on shadows, midtones and highlights. For each wheel: ordinary Reset resets both; Up Shift + Reset changes only color; Down Shift + Reset changes only luminance. Test quick chords and holds longer than one second, then release in both orders.
4. In the inspector, open Presses & Combinations and enable editing. Hold Previous Still and press Lum Mix. Release both. Confirm the captured gesture stays visible and no photo edits occurred.
5. Assign Preset 1 (configure that slot in Lightroom’s plug-in options first). Choose Done Programming. Repeat the gesture: only the preset should fire, with no bracket mark and no Lum Mix reset. Tap Previous Still alone: its original action should still work. Repeat the trigger twice while holding Previous Still.
6. Add a second held button with the mouse and assign another preset. Confirm the more specific combination wins. Test a normal button as the target and a knob press as a modifier.
7. Edit/remove combinations, undo/redo, export/import a map, and restart. Verify assignments persist and deleted defaults stay deleted. Restore a knob press to reset using its inspector control.
8. Open What’s New from the menu bar and Settings. Scroll to older releases. Check the layout at the smallest window size and with Reduce Motion enabled.

9. Repeat fast presses on Saturation and every other knob, including a small turn while pressing. Verify one press resets and “Updating” clears when Lightroom reports its value. LED changes now wait until held buttons are released.
10. Hold Undo to show Rewind+, then hover briefly or click the preview. Release Undo: the expanded workspace stays open. Use its mouse slider and playback controls; click inside before testing keyboard shortcuts. Collapse should restore the normal notch readout.
11. Select a branch node; selection alone must not edit the photo. Choose View to see its result, or check specific sliders and merge into a new result. Verify both source connections and source histories remain. Delete an unused inactive leaf, confirm, then Undo Delete. Confirm parent/current/original branches cannot be deleted. Try a smaller display and Reduce Motion.
