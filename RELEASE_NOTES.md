# PanaLux v1.0.0

**One panel. Every job.**

Use your Micro Color Panel to edit stills in Lightroom Classic.

- Grade with the three trackballs, rings, and twelve knobs. Use several controls at once and see up to six values in the readout.
- Hold keys for Color Mixer, Transform, masks, crop, culling, curves, detail, effects, optics, and presets.
- Hold Add Node to choose a mask from the circular tool wheel. Select New, Add, Subtract, or Intersect, then release to create it. Place it with the mouse. Trackball placement is coming soon.
- Remap every control from a catalog of 999 Lightroom commands. Give each key separate tap and hold jobs. Export and share `.panalux.json` maps.
- Send selected photos through the Grab Still Photoshop round-trip. PanaLux also releases the panel while Resolve is open and takes it back when Resolve quits.

Pause Output, Safe Setup, Back to Base, and map backups are included.

Requires macOS 14 or later, a USB-C Micro Color Panel, and Lightroom Classic. Install the plugin from the app. This release is not notarized. First launch: **System Settings > Privacy & Security > Open Anyway**.
